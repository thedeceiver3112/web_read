⚙️ Cài Đặt Đọc Truyện Ngụy Trang Excel

1. Nạp File PDF Truyện

Chọn file PDF tiểu thuyết / truyện chữ của bạn từ máy tính. Hỗ trợ đọc cả trang đầu (bìa/mục lục) lẫn các chương truyện chính.

Kéo & thả file PDF vào đây hoặc Chọn tệp

2. Phím Tắt Khẩn Cấp (Boss Key)

  • ESC : Chuyển ngay lập tức sang bảng số liệu tài chính Doanh Thu (bấm lại để đọc tiếp).
  • ↓ hoặc J : Sang dòng/câu truyện tiếp theo.
  • ↑ hoặc K : Lùi lại dòng trước.
  • PageDown / PageUp : Sang trang PDF tiếp / trang trước.
  • Space : Bật / tắt chế độ tự động cuộn (Auto-advance).

3. Chế Độ Đọc Siêu Tàng Hình

Bảng Kiểm Toán (Cột D)

Mỗi câu/đoạn truyện là 1 dòng trong cột "Audit Log Finding". Trông giống hệt nhật ký ghi chú hệ thống.

Thanh Công Thức (Ninja)

Bảng hiển thị số liệu 100%, câu truyện CHỈ xuất hiện trên thanh công thức fx ở đỉnh màn hình.
