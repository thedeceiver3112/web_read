3. Phím Tắt Khẩn Cấp (Boss Key) & Điều Khiển

  • ESC hoặc F2 : Chuyển ngay sang bảng số liệu tài chính doanh thu hoặc code backend thuật toán (bấm lại để đọc tiếp).

  • ↓ hoặc J : Chuyển sang câu/dòng tiếp theo.
  • ↑ hoặc K : Lùi lại dòng trước.
  • PageDown / PageUp : Sang phần đọc tiếp theo / phần trước.
  • Space : Bật / tắt chế độ tự động cuộn (Auto-advance).
